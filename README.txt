Package contents
- index.html: responsive executive portfolio website

How to publish
1. Extract this ZIP file.
2. Upload index.html to the root of your GitHub Pages repository, replacing the existing index.html.
3. Commit the change and allow GitHub Pages to deploy.
4. Open the published website and review it on desktop and mobile.
